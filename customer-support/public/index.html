Ready to start

Offline preview · Replies are simulated. Connect your Project key to run a real Agent.

Connect to ZooWork Platform
  1. Sign in to Platform Console ↗, select a Project, then open API Keys and create a key.
  2. Copy .env.example to .env. Set ZOOWORK_API_KEY to your zwp_live_ key and keep the matching ZOOWORK_BASE_URL. Keep the key on your server; never paste it into this chat.
  3. Check Organization billing and credits in the Console. Real model turns use credits.
  4. Stop the offline preview with Ctrl+C, then run these commands from customer-support/: 
npm run setup
npm run dev

Setup creates and starts your Agent through the SDK. Reopen this page after the server starts; the offline label will disappear. See README.md for the full setup and troubleshooting guide.
