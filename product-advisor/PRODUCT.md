# Product Advisor

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
React + Vite, Node 22, Express, SQLite, published ZooWork SDK; confirmed implementation plan in PLAN.md.

## Users
Developers evaluating a complete Platform remote MCP application, and visitors selecting catalog products by budget and requirements.

## Product Purpose
Search, compare and shortlist products, with inspectable facts from actual remote MCP results.

## Operating Context
An independently installed local application, plus a separately hosted read-only public MCP catalog. Platform executes the tools. The browser uses the application's backend.

## Capabilities and Constraints
Three synthetic categories: laptops, monitors, headphones. Search is automatic; details and comparison use native approvals. Unknown facts stay unknown. Session history, ownership and recovery are required. Public hosting needs separate authorization. There are no real purchases or market price claims.

## Evidence on Hand
The agreed PLAN.md, foundation SDK lifecycle code and current Platform source contracts. Product fixtures are clearly labeled synthetic. Live application evidence is not yet available.

## Product Principles
Show useful selection results before technical logs. Check product facts against remote evidence. Preserve denied and failed states. Do not create additional paid turns automatically.

## Brand Commitments
Product Advisor is the application name. The user has not specified a visual brand; functional catalog styling is a session assumption.

## Accessibility & Inclusion
Keyboard access, legible contrast, responsive desktop/mobile web and readable unknown/error states.
