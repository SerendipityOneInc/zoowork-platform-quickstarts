# Third-party components

registries and then edited here. Everything else in the starter is covered
by the license at the repository root.

with the assistant-ui CLI (`npx assistant-ui@latest add thread thread-list
markdown-text tool-fallback reasoning tool-group`). Files not used by the
starter were removed, and `thread.aui.tsx`, `thread-list.aui.tsx`,
`tool-fallback.aui.tsx` and `markdown-text.tsx` were edited. License text from the `@assistant-ui/react`

registry depends on). The CLI is not a dependency of the starter; the state
